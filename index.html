Project Information

Vehicle & Door Setup

Top-view (X forward, Y left). Simplified single-axis hinge rotation. Door leaf extends from the hinge; height is vertical (not shown in top view).

Door positions 0–100% in 10% steps are generated automatically (11 positions, criterion 4). Use the door slider above the canvas to view any position.

Sensor Setup

Position & orientation are in the door-local frame (origin = hinge). The sensor moves and rotates with the door.

Obstacle Setup

Obstacle positions are in the vehicle frame.

Static FOV Test Points

Enable “Add point on click”, then click the canvas — a test point is created at the current door position, and its in-FOV status (PASS/FAIL) is computed automatically. Points can also be added manually.
