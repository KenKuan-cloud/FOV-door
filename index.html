Project Information

Wing-Door Setup

Front view (Y horizontal, Z up). Falcon-/gullwing door hinged near the roof; it lifts up-and-out about the hinge in the Y–Z plane. LH vs RH mirrors the swing direction.

Import outline from CAD (SVG)

Imports the largest outline; hinge is placed at its top-center. Points land in the editable box above for fine-tuning.

Door positions 0–100% in 10% steps are generated automatically (11 positions, criterion 4). Use the door slider above the canvas to view any position, and enable Swept FOV to see all positions at once.

Sensor Setup

Position (door-local Y,Z, origin = hinge) and yaw are fixed to the door — the sensor lifts and rotates with it. Yaw is the sensing direction in the Y–Z plane, measured CCW: 0 = +Y, 90 = up (+Z), 180 = −Y, 270 = down. For a LH door, outboard-down is around 195–200°.

Obstacle Setup

Obstacle positions are in the vehicle frame; the front view uses Y (horizontal) and Z (height). X is fore-aft.

Static FOV Test Points

Enable “Add point on click”, then click the canvas — a test point is created at the current door position, and its in-FOV status (PASS/FAIL) is computed automatically. Points can also be added manually.

Sensor Overlap Analysis (§11.4)

Coverage from all active sensors at the current door position: where two or more FOVs overlap (redundant, robust to a single blocked sensor), where only one covers, and gaps between sensors (§24.6). Sensors are rigidly mounted, so overlap is the same at every door angle.

Door-Movement Compensation (§13)

The sensor rides the door, so it has an ego velocity (ω × lever arm). A radar sees the obstacle relative to the moving sensor; the sensor's radial ego velocity must be subtracted to recover the true object velocity. Computed at the current door position.

Enter the radar-measured relative radial velocity per obstacle — closing convention, + = approaching. Comp = Measured − Ego radial (§13). A stationary obstacle reads Measured ≈ +Ego, so its compensated velocity ≈ 0.

Configuration Comparison (§11.4)

Config A is the current project. Load a second saved project as Config B to compare FOV, coverage, blind zones, and reaction margin — e.g. sensor position/angle A vs B, 1 vs 2 sensors, or original vs revised.

Dynamic Door Analysis

Sweeps the opening door and, for each obstacle, finds when it first enters the sensor FOV vs. when the moving door would contact it — then the available reaction time, system response time, and safety margin (§12, §34).
