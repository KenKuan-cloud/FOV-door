Wing-Door Setup

Front view (Y horizontal, Z up). Falcon-/gullwing door hinged near the roof; it lifts up-and-out about the hinge in the Y–Z plane. LH = left door (right of screen from front); RH = right door (left of screen).

Door positions 0–100% in 10% steps are generated automatically (11 positions, criterion 4). Use the door slider above the canvas to view any position, and enable Swept FOV to see all positions at once.

Sensor Setup

Position (door-local Y,Z, origin = hinge) and yaw are fixed to the door — the sensor lifts and rotates with it. Yaw is the sensing direction in the Y–Z plane, measured CCW: 0 = +Y, 90 = up (+Z), 180 = −Y, 270 = down. For a LH door, outboard-down is around 195–200°.

Obstacle Setup

Obstacle positions are in the vehicle frame; the front view uses Y (horizontal) and Z (height). X is fore-aft.

Static FOV Test Points

Enable “Add point on click”, then click the canvas — a test point is created at the current door position, and its in-FOV status (PASS/FAIL) is computed automatically. Points can also be added manually.
